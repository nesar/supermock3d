# SuperMock 3D

A lightweight web front‑end for visualising mock 3‑D catalogs generated from the SuperMock pipeline. The repository contains:

- **HTML/JS** UI (`index.html`, `app.js`, `inspect.js`)
- **Binary data** (`data/` directory) for sky tiles, magnitudes, redshifts, etc.
- A small set of utilities for loading the binary files in the browser.

The project is primarily used internally at Argonne for quick inspection of synthetic sky maps. It is MIT‑licensed and open to contributions that improve the UI or add documentation.
