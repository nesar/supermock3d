# Number counts and luminosity function

<div class="small">

- The $r$-band counts agree with the Blanton et al. (2003) prediction to **0.070 dex** (mean |Δ|, 15 < $r$ < 19.5, 19 patches). This range is the count part of the dust calibration, fitted on patch 4. So this is a consistency check across patches, not an independent test. Fainter than $r \approx 19$ the mock lies above the curve because the prediction stops at $z$ = 0.55.
- Rest-frame $M_r$ luminosity function at 0.05 < $z$ < 0.2: within 0.9 to 1.2 of Blanton et al. for $M_r$ = −20 to −23. About 6× low at $M_r$ = −18 (core mass floor).
