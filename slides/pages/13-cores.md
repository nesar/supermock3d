# Cores: tracked halo centres instead of subhalos

- A **core** is the set of most-bound particles of a halo, followed after the halo falls into a larger one. It stands in for the subhalo that would host a satellite galaxy.
- Each core carries a state per output: **central**, **satellite**, or **merged** (inside its host's merging radius, set by HACC's core analysis). Merging is terminal: no core leaves state 2.
- Cores are **seeded at 80 particles** (2.17 × 10¹¹ $h^{-1}$M$_\odot$). The cut is sharp: no core in the catalog has a lower peak mass. This sets the mass floor of the galaxy catalog.
- Per patch: 76.9% centrals, 15.4% satellites, 7.7% merged cores.
