# Terms used in this deck

<div class="small">

| term | meaning |
|---|---|
| core | the most-bound particles of a halo, followed in time after the halo falls into a larger one. A core is where a galaxy sits. |
| central / satellite / merged core | a core in its own halo / a core inside a larger halo / a core that has reached the centre of its host (final state) |
| forest | the file with the mass history of every core over the 101 simulation outputs |
| lightcone | the set of cores at the place and time where their light reaches the observer today |
| patch | one of 192 equal-area pieces of the sky (214.9 deg²). We run the pipeline one patch at a time. |
| UniverseMachine (UM) | an empirical galaxy model run on the SMDPL simulation. We take star-formation histories from it. |
| SFH | star-formation history: the star-formation rate of a galaxy at 117 times |
| SED, spectrum | the energy of a galaxy at each wavelength |
| FSPS, C3K | the stellar-population code we use, and the library of stellar spectra inside it |
| dust amount ($\tau_V$, $A_V$) | how much starlight the dust absorbs at 0.55 µm; $A_V = 1.086\,\tau_V$ magnitudes |
| infrared templates | fixed shapes of the dust emission spectrum (Draine & Li 2007) |
| cut sample | the galaxies with $i_{\rm LSST}$ < 25.5 or W1$_{\rm AB}$ < 20.5. All validation plots use it. |

</div>
