# The simulation: LastJourney

| | |
|---|---|
| code | HACC, gravity only |
| box | 3400 $h^{-1}$Mpc |
| particles | 10752³ = 1.24 × 10¹² |
| particle mass | 2.72 × 10⁹ $h^{-1}$M$_\odot$ |
| cosmology | $\Omega_m$ 0.3096, $\Omega_b$ 0.0490, $h$ 0.6766, $\sigma_8$ 0.8102, $n_s$ 0.9665 |
| time steps | 500 from $z$ = 200; 101 outputs kept (steps 42 to 499) |

We use three products: the core catalog, the core merger forest (the mass history of each core over the 101 outputs), and the core lightcone built from them.

Caption: Heitmann et al. 2021, ApJS 252, 19.
